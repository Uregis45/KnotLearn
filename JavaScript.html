Variables

Lesson 2 of 4

Variables store data like numbers, text, or booleans. Use let to create a variable.

let isLearning = true;

Simple Addition

Lesson 4 of 4

JavaScript can do math operations — read inputs, calculate, and display results on the page.

JS function add() {
  let a = Number(document.getElementById("num1").value);
  let b = Number(document.getElementById("num2").value);
  let sum = a + b;
  document.getElementById("result").innerText = sum;
}
