📖 HTML Basics

10 lessons to get you started with web development

💡

1. What is HTML?

HTML stands for HyperText Markup Language.
It is used to create webpages and structure content on the internet.

📌 Key Point:

HTML is the structure of a website — like the skeleton of a building.
📄

2. Basic HTML Structure

This is the basic structure of every HTML page:

<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    Hello World!
  </body>
</html>
🔤

3. HTML Headings

HTML has headings from <h1> to <h6>:

<h1>Heading 1 - Most Important</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6 - Least Important</h6>

4. HTML Paragraph

The <p> tag is used to write text:

<p>This is a paragraph of text.</p>
<p>This is another paragraph.</p>
🔗

5. HTML Links

Use the <a> tag to create links:

<a href="https://www.google.com">Go to Google</a>

🎯 Live Example:

🖼️

6. HTML Images

Use the <img> tag to add images:

<img src="image.jpg" alt="Description of image">
📋

7. HTML Lists

Unordered list (bullets):

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Ordered list (numbers):

<ol>
  <li>First step</li>
  <li>Second step</li>
  <li>Third step</li>
</ol>
🔘

8. HTML Buttons

Use the <button> tag to create clickable buttons:

<button>Click Me</button>

9. HTML Forms

Forms collect user input:

<form>
  <input type="text" placeholder="Your name">
  <button type="submit">Submit</button>
</form>
🚀

10. Conclusion

HTML is easy to learn and very important.
After HTML, you should learn CSS and JavaScript.
