HTML Basics

Everything you need to build your first webpage — step by step

💡

What is HTML?

Lesson 1 of 10

HTML stands for HyperText Markup Language. It is used to create webpages and structure content on the internet.

📌 Key Point

HTML is the structure of a website — like the skeleton of a building. Every webpage you visit is built with HTML.
📄

Basic HTML Structure

Lesson 2 of 10

This is the basic structure of every HTML page — every HTML file must include these elements:

HTML<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    Hello World!
  </body>
</html>
🔤

HTML Headings

Lesson 3 of 10

HTML has 6 heading levels from <h1> (most important) to <h6> (least important):

HTML<h1>Heading 1 — Most Important</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h6>Heading 6 — Least Important</h6>

HTML Paragraphs

Lesson 4 of 10

The <p> tag is used to write blocks of text. Each paragraph is separated automatically.

HTML<p>This is a paragraph of text.</p>
<p>This is another paragraph.</p>

HTML Links

Lesson 5 of 10

Use the <a> tag to create clickable links. The href attribute holds the URL.

HTML<a href="https://www.google.com">Go to Google</a>

🎯 Live Preview:

HTML Images

Lesson 6 of 10

Use the <img> tag to embed images. It's a self-closing tag — it has no closing tag.

HTML<img src="image.jpg" alt="Description of image">

📌 Key Point

Always add an alt attribute — it describes the image for accessibility and shows when the image can't load.
📋

HTML Lists

Lesson 7 of 10

HTML has two types of lists. Unordered uses bullet points; ordered uses numbers.

HTML — Unordered<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>
HTML — Ordered<ol>
  <li>First step</li>
  <li>Second step</li>
</ol>

HTML Buttons

Lesson 8 of 10

Use the <button> tag to create clickable buttons. Pair with JavaScript to make them interactive.

HTML Forms

Lesson 9 of 10

Forms collect user input. The <form> tag wraps <input> fields and a submit button.

HTML<form>
  <input type="text" placeholder="Your name">
  <button type="submit">Submit</button>
</form>
