🎯 CSS Fundamentals

6 lessons to master cascading style sheets

💅

1. What is CSS?

CSS stands for Cascading Style Sheets.
CSS styles a web page — colors, size, layout, and design.

body {
  background-color: lightblue;
  font-family: Arial, sans-serif;
}

📌 Key Point:

HTML = structure, CSS = style, JavaScript = behavior
🎨

2. Colors & Text

Change text color, size, and font family:

h2 {
  color: red;
  font-size: 24px;
  font-weight: bold;
  text-align: center;
}

3. Box Model

Every element is a box with margin, border, padding, and content.

div {
  width: 200px;
  padding: 20px;
  margin: 10px;
  border: 2px solid black;
  border-radius: 8px;
}

4. Buttons

Style buttons with CSS:

button {
  background-color: #0f39ac;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 50px;
  cursor: pointer;
  font-size: 16px;
}

5. Flexbox

Align items easily with Flexbox:

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 10px;
}

6. Card Design

Modern UI using CSS:

.card {
  background: white;
  padding: 20px;
  border-radius: 12px;
  box-shadow: 0 4px 15px rgba(0,0,0,0.1);
  transition: transform 0.2s;
}
.card:hover {
  transform: translateY(-5px);
}
