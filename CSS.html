What is CSS?

Lesson 1 of 6

CSS stands for Cascading Style Sheets. It styles a web page — colors, size, layout, and design.

CSS body {
  background-color: lightblue;
  font-family: Arial, sans-serif;
}
🧱 HTML = structure  |  🎨 CSS = style  |  ⚡ JavaScript = behavior
Think of HTML as the skeleton, CSS as the clothes, and JS as the movement.
🎨

Colors & Text

Lesson 2 of 6

Change text color, font size, weight, and alignment using CSS properties:

CSS h2 {

  font-weight: bold;
  text-align: center;

The Box Model

Lesson 3 of 6

Every HTML element is a box with four layers: margin (outside space), border (frame), padding (inside space), and content (the actual text/image).

CSS div {
  width: 200px;
  padding: 20px;
  margin: 10px;
  border: 2px solid #0f39ac;
  border-radius: 8px;
}

Styling Buttons

Lesson 4 of 6

Style buttons to look modern and professional. Use border-radius for rounded corners and transition for smooth hover effects:

CSS button {
  background-color: #0f39ac;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 50px;
  transition: all 0.2s;
}
button:hover {
  transform: translateY(-2px);
}

Flexbox Layout

Lesson 5 of 6

Flexbox makes it easy to align and arrange items in a row or column. It's the most useful CSS layout tool:

CSS .container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 10px;
}

Card Design

Lesson 6 of 6

Cards are one of the most popular UI patterns. Use box-shadow for depth and transition for a smooth hover lift effect:

CSS .card {
  background: white;
  padding: 20px;
  border-radius: 12px;
  box-shadow: 0 4px 15px rgba(0,0,0,0.1);
  transition: transform 0.2s;
}
.card:hover {
  transform: translateY(-5px);
}
